## Namao for Android 1.0.0

The first public Android build: a Material 3 client for your own self-hosted Namao server.

**Namao is a client, not a downloader.** The app does no downloading itself. You need a running Namao
server (see the [README](../../README.md#run-it)) and enter its address on first launch. Without one the app has nothing to talk to.

### What it does
- Paste a link from YouTube, Facebook, TikTok, X or Instagram, see the qualities the source really offers (with size estimates where known), and download.
- Real progress from the server (percent, speed, time left, bytes), including separate merge and verify stages. Cancel and retry.
- Active / Completed / Failed lists that survive restarts; finished files are checked for exact size and saved to `Download/Namao` (no storage permission needed).
- Open or share a saved file; light, dark and system themes; works with a larger system font size.

### Requirements
- Android 10 (API 29) or newer.
- A Namao server reachable from the phone (your LAN address or an https URL).

### Known limits
- The phone-side file transfer runs under a foreground service but stops if you swipe the app away; the interrupted transfer is detected on the next launch and offered as **Retry save**.
- Tested on an Android 16 (API 36) emulator and with automated tests. Not yet tested on a physical device or with TalkBack.
- No real YouTube / Facebook / TikTok / X / Instagram download has been run through this app; platforms can throttle or block a server's address.
- Personal use only. Namao does not bypass DRM, logins or paywalls.

### Install
1. Download `namao-android.apk` from the assets below.
2. Optional but recommended: check the SHA-256 (see the table below).
3. Open the file on your phone and allow "Install unknown apps" for your browser or file manager when Android asks.
4. Launch **Namao**, enter your server address, and tap **Test connection**.

### Update
Install a newer `namao-android.apk` over the old one. Your history and settings are kept, because every release is signed with the same key.
