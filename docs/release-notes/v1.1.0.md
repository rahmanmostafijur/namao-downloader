## Namao for Android 1.1.0

**Namao now downloads on your phone.** No server, address or Wi-Fi setup: paste a link, pick a quality, and the video is saved to `Download/Namao`. The downloader is built into the app.

### What changed
- The app no longer needs a Namao server. The server address, test-connection and first-run setup screens are gone.
- Downloading, merging audio and video, and MP3 conversion all happen on the phone. Internet is needed only to reach the video's site.
- The app refreshes its downloader from yt-dlp's official release (checked against the published SHA-256) so sites keep working. The first launch does this before your first link, so the first link takes longer.
- Plain wording everywhere: "Preparing your download…", "Downloading 42%", "Finishing…", and short, clear errors.
- A notification shows real progress while a download runs in the background.
- New **Settings > Open-source licenses** page. The bundled downloader is GPL-3.0 software; see [docs/android-engine.md](../android-engine.md).
- The download is the 64-bit ARM build (about 62 MB), which covers practically every Android phone sold in recent years. It will not install on 32-bit-only phones or x86 emulators.
- Namao is now released under the GPL-3.0 (see `LICENSE`), as required by the bundled downloader.

### Requirements
- Android 10 (API 29) or newer.
- An internet connection.

### Known limits
- Swiping the app away from Recents stops a running download; it shows as **Interrupted** with Retry next time.
- Downloads from the 1.0.1 server version appear as **Interrupted** after updating.
- Tested on an Android 16 (API 36) emulator and with automated tests (305). Not yet on a physical device or with TalkBack.
- Only YouTube was exercised on a device. Facebook, TikTok, X and Instagram use the same engine but are untested, and may need a refresh when they change.
- On the test emulator the first link took about two minutes (starting the downloader is slow there); real phones should be faster but this was not measured.
- Personal use only. Namao does not bypass DRM, logins or paywalls.

### Install
1. Download `namao-android.apk` from the assets below.
2. Optional but recommended: check the SHA-256 (see the table below).
3. Open the file on your phone and allow "Install unknown apps" for your browser or file manager when Android asks.
4. Launch **Namao** and paste a link.

### Update
Install a newer `namao-android.apk` over the old one. History is kept because every release is signed with the same key.
